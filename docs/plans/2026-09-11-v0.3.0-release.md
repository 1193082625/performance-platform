# v0.3.0 Release Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 v0.2.0 之后已经完成的精准诊断、当前告警、SDK 生命周期与 Reporter 可靠性、内存和 1H 图表修复封版为 v0.3.0。

**Architecture:** 本次只做发布一致性和验收，不引入新的运行时能力。版本号、用户文档、部署配置和测试名称统一为 v0.3.0，并以全量自动化和 Docker 完整链路作为发布门槛。

**Tech Stack:** pnpm workspace、TypeScript、Vue、Vitest、Playwright、Docker Compose、Git。
